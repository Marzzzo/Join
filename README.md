# Join – Kanban Project Management

Join is a task management application inspired by the Kanban system. It helps users organize tasks, manage contacts, and keep track of their project's progress.

## Features

- Create and manage tasks
- Organize tasks in a Kanban board
- Drag and drop tasks between different categories
- Assign tasks to contacts
- Set priorities and due dates
- Add subtasks
- Manage contacts
- User authentication
- Responsive design for desktop and mobile devices

## Technologies

- Angular
- TypeScript
- HTML
- CSS
- Firebase
